--------------------------------------------------------------------------------
1. THEORY
--------------------------------------------------------------------------------
YACC (Yet Another Compiler-Compiler) is a parser generator used to create the
syntax analyzer (parser) of a compiler. It takes a Context-Free Grammar (CFG)
as input and automatically generates C code for parsing input tokens. YACC is
generally used along with LEX, where LEX performs lexical analysis and YACC
performs syntax analysis.


--------------------------------------------------------------------------------
2. FEATURES OF YACC
--------------------------------------------------------------------------------
1. Generates parser automatically from grammar rules.
2. Detects syntax errors in the input.
3. Supports Context-Free Grammar (CFG).
4. Works efficiently with LEX.
5. Produces C source code (y.tab.c) for parsing.


--------------------------------------------------------------------------------
3. STRUCTURE OF YACC PROGRAM
--------------------------------------------------------------------------------
A YACC program consists of 3 sections:

--------------------------------------------------
%{
    /* Declarations: global variables, prototypes, header files (#include), comments */
%}
    /* Token declarations (%token), precedence rules, etc. */
%%
    /* Production Rules Section (Grammar is checked, semantic actions inside { }) */
%%
    /* User Subroutines / C Auxiliary Code Section (main(), yyerror(), helper functions) */
--------------------------------------------------

1) Definition Section:
   - Header files (#include)
   - Token declarations (%token)
   - Variable declarations
   - C code declarations

2) Rules Section:
   - Contains grammar and production rules.
   - Semantic actions are written inside { }.

3) User Subroutine Section:
   - Contains functions such as:
     * main()
     * yyerror()
     * Helper / auxiliary functions


--------------------------------------------------------------------------------
4. WORKING OF YACC
--------------------------------------------------------------------------------
1. Grammar rules are written in a .y file (e.g., x.y).
2. YACC compiles the .y file and generates the parser in C (y.tab.c).
3. LEX compiles a .l file and generates the lexical analyzer (lex.yy.c).
4. Both files (y.tab.c and lex.yy.c) are compiled together using a C compiler (e.g., cc / gcc).
5. The parser reads tokens from LEX and checks whether the input follows the grammar.

Flow:
  x.y ----[ YACC ]----> y.tab.c ----\
                                      +----[ CC / GCC ]----> a.out (Executable)
  x.l ----[ LEX  ]----> lex.yy.c ---/


--------------------------------------------------------------------------------
5. BUILT-IN FUNCTIONS OF YACC
--------------------------------------------------------------------------------
1) yyparse():
   - Main parser function.
   - Starts syntax analysis and calls yylex() to obtain tokens.

2) yylex():
   - Lexical analyzer function generated by LEX.
   - Returns tokens to YACC.

3) yyerror(char *s):
   - Called automatically whenever a syntax error occurs.
   - Used to display error messages.


--------------------------------------------------------------------------------
6. BUILT-IN VARIABLES OF YACC
--------------------------------------------------------------------------------
1) yylval:
   - Stores the semantic value of the current token.
   - Used for passing values from LEX to YACC.

2) yychar:
   - Stores the current input token.

3) yydebug:
   - Used for debugging the parser.
   - Displays parser execution trace when enabled.

4) yyin:
   - Input file pointer (shared with LEX).
   - Specifies the input file to be parsed.


--------------------------------------------------------------------------------
7. APPLICATIONS
--------------------------------------------------------------------------------
1. Compiler construction and syntax checking.
2. Expression evaluation.
3. Programming language interpreters.
4. Domain-Specific Language (DSL) development.


--------------------------------------------------------------------------------
8. ADVANTAGES
--------------------------------------------------------------------------------
1. Automatically generates parser.
2. Easy to define grammar rules.
3. Detects syntax errors efficiently.
4. Integrates easily with LEX.
5. Reduces parser coding effort.


--------------------------------------------------------------------------------
9. CONCLUSION
--------------------------------------------------------------------------------
YACC is a parser generator that automatically creates a syntax analyzer from
grammar rules. When combined with LEX, it simplifies compiler design by
performing efficient syntax analysis and detecting grammatical errors in the
input program.
