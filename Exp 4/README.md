# Experiment 4 — Introduction to YACC Tool

## Aim
Introduction to YACC tool, and format to write the YACC code.

---

## Theory
**YACC** (*Yet Another Compiler-Compiler*) is a parser generator used to create the syntax analyzer (parser) of a compiler. It takes a Context-Free Grammar (CFG) as input and automatically generates C code for parsing input tokens.

YACC is generally used along with **LEX**, where LEX performs lexical analysis and YACC performs syntax analysis.

---

## Features of YACC
1. Generates parser automatically from grammar rules.
2. Detects syntax errors in the input.
3. Supports Context-Free Grammar (CFG).
4. Works efficiently with LEX.
5. Produces C source code (`y.tab.c`) for parsing.

---

## Structure of a YACC Program
A YACC program (`.y` file) consists of three sections separated by `%%`:

```yacc
%{
/* Definition Section: Header files, global variables, function prototypes */
%}

/* Token declarations (%token), precedence rules, etc. */

%%
/* Rules Section: Production rules and semantic actions inside { } */
%%

/* User Subroutine Section: C auxiliary functions like main(), yyerror() */
```

### 1. Definition Section
- Header files (`#include`)
- Token declarations (`%token`)
- Variable declarations
- C code declarations

### 2. Rules Section
- Contains grammar and production rules.
- Semantic actions associated with productions are written inside `{ }`.

### 3. User Subroutine Section
- Contains auxiliary C functions:
  - `main()`: Entry point of the program.
  - `yyerror(char *s)`: Error handling function called on syntax errors.
  - Helper functions.

---

## Working of YACC
1. Grammar rules are written in a `.y` file (e.g., `x.y`).
2. YACC compiles `x.y` to generate the parser (`y.tab.c`).
3. LEX compiles `x.l` to generate the lexical analyzer (`lex.yy.c`).
4. Both files are compiled together with a C compiler.
5. The parser reads tokens from LEX and checks whether the input follows the grammar.

```
x.y ----[ YACC ]----> y.tab.c ----\
                                    +----[ cc / gcc ]----> a.out
x.l ----[ LEX  ]----> lex.yy.c ---/
```

---

## Built-in Functions of YACC
| Function | Description |
| :--- | :--- |
| `yyparse()` | Main parser function; begins syntax analysis and calls `yylex()` to obtain tokens. |
| `yylex()` | Lexical analyzer function generated by LEX; returns tokens to YACC. |
| `yyerror(char *s)` | Called automatically whenever a syntax error occurs; displays error messages. |

---

## Built-in Variables of YACC
| Variable | Description |
| :--- | :--- |
| `yylval` | Stores semantic value of current token; used to pass values from LEX to YACC. |
| `yychar` | Stores the current lookahead input token code. |
| `yydebug` | Used for debugging the parser; displays parsing steps when enabled (`1`). |
| `yyin` | Input file pointer (`FILE *`) shared with LEX; specifies the input stream. |

## Applications
1. Compiler construction and syntax checking.
2. Expression evaluation.
3. Programming language interpreters.
4. Domain-Specific Language (DSL) development.

---

## Advantages
1. Automatically generates parser code.
2. Easy and standardized way to define grammar rules.
3. Detects syntax errors efficiently.
4. Integrates seamlessly with LEX.
5. Significantly reduces parser coding and maintenance effort.

---

## Conclusion
YACC is a parser generator that automatically creates a syntax analyzer from grammar rules. When combined with LEX, it simplifies compiler design by performing efficient syntax analysis and detecting grammatical errors in the input program.
